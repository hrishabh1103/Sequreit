# SeQureit — Cryptographic Intelligence for a Quantum-Safe World

> *"You cannot migrate what you cannot see."*

SeQureit is a deep-tech cybersecurity platform delivering cryptographic intelligence and crypto-agility to critical enterprises across BFSI, Defence & Aerospace, Telecom, Energy, and Government.

---

## 🚀 Overview

SeQureit provides an end-to-end cryptographic control layer that guides enterprises across the full transition lifecycle:

$$\text{Discover} \longrightarrow \text{Inventory} \longrightarrow \text{Understand} \longrightarrow \text{Assess} \longrightarrow \text{Prioritize} \longrightarrow \text{Remediate} \longrightarrow \text{Validate} \longrightarrow \text{Continuously Manage}$$

### Core Pillars
1. **Multi-Surface Continuous Discovery**: AST code static analysis, dynamic TLS/network probes, and cloud posture ingestion.
2. **Living CBOM (Cryptography Bill of Materials)**: Normalized cryptographic asset registry grounded in verifiable line-of-code call sites, certificate serials, and cloud URIs.
3. **Cryptographic Blast-Radius & Dependency Topology**: Visualizes ripple effects of cipher depreciation across service meshes.
4. **HNDL (Harvest Now, Decrypt Later) Risk Prioritization**: Multi-factor vulnerability scoring accounting for data retention lifetimes and adversary interception.
5. **Seamless Remediation & Agility**: Hybrid Post-Quantum VPN tunnels (ML-KEM-768 + classical X25519) and zero-downtime cryptographic shims.

## 💻 Getting Started Locally

### Prerequisites
- Node.js 18+
- npm / pnpm / yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/hrishabh1103/Sequreit.git

# Navigate into project directory
cd Sequreit

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
